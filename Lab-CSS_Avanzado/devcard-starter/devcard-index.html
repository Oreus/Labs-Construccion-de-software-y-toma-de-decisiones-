Reflexión Teórica

¿Diferencia entre padding y margin? El padding es espacio interno; el margin es espacio externo.

¿Por qué border-box? Para que el tamaño total incluya el borde y el relleno sin "romper" el layout.

¿Qué es Mobile-First? Diseñar para pantallas pequeñas primero y escalar hacia arriba.

¿rem sobre px? Se usa rem para que el diseño sea escalable y accesible según la fuente del navegador.
