Pregunta 3: ¿Cuál es el propósito de los métodos HTTP: GET, HEAD, POST, PUT, PATCH, DELETE?

  1. GET: El metodo GET recolecta informacion de un servidor
  2. HEAD: El metodo HEAD recolecta solo los headers de un servidor
  3. POST: El metodo POST crea nuevos "objetos" dentro de un servidor
  4. PUT: El metodo PUT remplaca un "objeto" completamente dentro de un servidor
  5. PATCH: El metodo PATCH remplaca atributos especificos en un "objeto" dentro de un servidor
  6. DELETE: El metodo DELETE borra un "objeto" dentro de un servidor

Pregunta 9: ¿Qué significa que un atributo HTML5 esté depreciado o desaprobado (deprecated)? Menciona algunos elementos de HTML 4 que en HTML5 estén desaprobados.

Significa que a base de las normas web actuales, ya no son recomendados. Unos ejemplos de elementos de HTML 4 que en HTML 5 estam desaprobados son:

  • HTML4: font : HTML5: font-family, color, etc.
  • HTML4: center : HTML5: text-align: center
  • HTML4: big : HTML5: font-size
  • HTML4: frame/frameset : HTML5: iframe
