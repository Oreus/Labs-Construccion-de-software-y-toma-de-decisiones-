Reflexion

¿Cuál es la diferencia entre padding y margin?

El padding es el espacio interno de un elemento (entre el contenido y el borde), mientras que el margin es el espacio externo (separa al elemento de sus vecinos).

¿Por qué se recomienda usar box-sizing: border-box?

Porque hace que el width y height incluyan el padding y el borde. Esto evita que los elementos se vuelvan más grandes de lo definido al añadirles espacio interno.

¿Qué significa diseñar con enfoque mobile-first?

Significa escribir primero los estilos para pantallas pequeñas y usar Media Queries para añadir complejidad en tablets y desktops. Mejora el rendimiento y la experiencia en móviles.

¿En qué situaciones preferirías rem sobre px?

Para tipografía y espaciado general, ya que rem es relativo al tamaño de fuente de la raíz, lo que permite que el diseño sea accesible y se adapte a las preferencias del usuario.
